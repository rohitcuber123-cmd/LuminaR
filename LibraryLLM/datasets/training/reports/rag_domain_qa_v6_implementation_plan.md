# V6 diagnostic-only implementation plan

**Decision B: rule-based domain-QA extraction is near diminishing returns.** No V6 extraction code was written. The frozen 40-chunk probe exposes only two reusable patterns with three plausible safe source structures. The conservative lower-bound recoverable estimate is **one** proposition, not three validated QA examples. Any later implementation requires a separate task and fresh validation gate.

| Pattern | Relation | Observed cues | Plausible source structures | Conservative recoverable estimate |
|---|---|---:|---:|---:|
| Named finite action with bounded direct object | ACTION | 2 | V6C-001, V6C-147 | 1 |
| Named person with complete “was determined to …” complement | ATTRIBUTE | 1 | V6C-003 | 0 until answer/category contract is proven |

**Named finite action.** Generic form: `NAME + finite lexical verb + complete direct object`, optionally followed by an explicitly marked location/time phrase. Required slots are exact subject, verb, object, answer, and clause spans. HIGH requires a named subject that owns the verb, a complete object boundary, one primary predicate, and a question whose specificity is supported by a source-explicit anchor. In V6C-001, a future rule could isolate “Lady Catherine opened the doors into the dining-parlour and drawing-room” before the later “pronouncing … walked on” actions. V6C-147 (“Alice gave a little scream of laughter”) is structurally clear but may not admit a sufficiently specific question under unchanged v2 without invented context, so it adds no lower-bound yield. Unsafe variants include an unresolved pronoun subject, coordinated second verb swallowed as object/context, a metaphorical verb, and a fabricated anchor. Required tests: named subject/object spans, object stops at coordination, second action never becomes context, explicit location anchor only, question passes unchanged v2, and frozen V4 ACTION_CONTEXT replay remains blocked. This pattern has the highest V4 regression risk; do not revive action-context drift.

**Complete named-person state/intention complement.** Generic form: `NAME + was + determined to + complete infinitival complement`. Required slots are named subject, copula, state marker, full infinitive/complement, and answer span. HIGH requires the complement to be self-contained, with no dangling preposition, ambiguous negation, or unresolved participant. V6C-003 is the only observed occurrence. Its proposed ATTRIBUTE/MOTIVATION category and exact answer boundary must be tested against the unchanged validator before any HIGH rule exists; therefore its conservative recoverable estimate is **0**. Unsafe variants include “was determined” without an action, “determined to do it” with an unresolved referent, and broad mental-state inference. Required tests: complete vs dangling complement, exact source offsets, category/question alignment, no pronoun dependency, low-value attribute handling, and preservation of all V4/V5 statement-fragment and discourse-dependency regressions.

No third SAFE_V6_CANDIDATE pattern is supported by the audit. Relation words without two grounded endpoints, unnamed motion actors, generic copulas, and quote fragments must remain diagnostic. The V5 quote cue counter’s after-emission placement should be fixed **as instrumentation only** in a separate task if cue statistics are used again; it did not suppress generation. No silent extractor or segmenter bug was found.

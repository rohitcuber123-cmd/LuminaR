# Compositional query grammar

V2C-A extends the accepted `QueryPlan`, `parse_query` and scoped execution/session paths. It adds no model, retrieval engine, session store, autocomplete or interactive clarification flow. `PARSER_VERSION` is `search-v2c-a-compositional-1`.

`query_constraints.Source` normalizes NFKC/case with a per-character original-offset map, protects quoted strings and identifiers, and accepts bounded non-overlapping candidates. Each candidate records field, comparator/value, original span/text, recognizer ID, support status and optional repair provenance. At most 500 input characters and the existing authorized facet bounds are used. Eight immutable vocabulary projections are cached by their full authorized contents; queries and user behavior are not cached by this projection.

Small recognizer families handle ratings, years, formats/availability, unsupported fields/sorts, exclusions and author/title requests. Specific spans are consumed before composing the remaining accepted facet/intent grammar. Hard values come from source spans or explicit validated API controls. Rating bounds compose by intersection, choosing the strongest lower/upper bound; comparator inclusivity remains explicit. Coordinated bounds borrow the immediately preceding field only across a grammatical conjunction, not arbitrary semantic text.

Supported rating constructions include field-first and comparator-first phrases, optional articles/of, star units, inclusive suffixes, extrema, equality and ranges. The scale is 0–5; out-of-range values are retained as recognition evidence and rejected without applying a false bound. Publication year supports explicit published/released cues, publication ranges/onward phrases and bare constraint-only year constructions. Historical events/about clauses retain year-shaped topics. The accepted format-qualified catalogue query pattern (such as online books about networking after 2020) retains publication filtering when no historical cue is present. This deterministic evidence heuristic is documented rather than claimed as general language understanding.

Canonical subject/alias resolution uses only the supplied authorized vocabulary. Existing conservative fuzzy thresholds remain; a unique adjacent transposition of at least six characters can also resolve to a real scoped facet. Proper-name corrections are not invented. Explicit by/titled phrases populate existing author/title filters; topical references stay semantic. Exact and Title/Author modes preserve literal numbers and punctuation. Quoted constraints are opaque to recognizers.

Format presence, stock/requestability and digital authorization remain distinct. `online only` retains accepted V2B selected-format-presence semantics; a book with both formats may qualify. Simultaneous incompatible ONLY selections are contradictory. Explicit `online but not physical` enforces actual opposite-format absence. Physical borrowing requires authoritative requestable physical stock, not merely an online entitlement. Per-copy not-on-loan, numeric page count, edition and unsupported sort requests receive an UNSUPPORTED decision; no fabricated strict metadata or chip is introduced.

Negative clauses are bounded before later recognized constraints, so a following rating does not become an excluded title phrase. `not only` and protected literal negation remain semantic. Exclusions stay authoritative over canonical matches, KG expansion and personalization. Short/beginner/advanced preferences use existing soft-preference semantics; no invented difficulty or page threshold is applied.

`query_repair` composes candidates, retains literal/topic spans, recognizes genuine unfinished field/operator cues and refuses to treat them as an executable garbage topic. `query_confidence` returns typed EXECUTABLE, EXECUTABLE_WITH_NOTICE, AMBIGUOUS, INCOMPLETE, UNSUPPORTED or CONTRADICTORY decisions. These categories are rule decisions, not calibrated probabilities. The original compatibility confidence scalar is retained but is not the acceptance authority.

Only executable decisions proceed to existing retrieval. Rejected plans return zero results and a compact edit-and-retry notice, skip KG/HNSW/CrossEncoder/profile access, and never replace or refresh the last accepted V2B plan. Existing scoped state, UTC expiry, JWT sid binding, clear/logout and authorization barriers remain. Old stored plans are readable via additive defaults; nonempty old-parser replay requests are revalidated without a bulk migration.

Public decisions omit internal candidates, spans, confidence internals and vocabulary. Tenant authorization precedes facet resolution and again precedes canonical hydration. Recommendation MACHINE calls bypass human parsing; Staff Inventory operational exact search is untouched.

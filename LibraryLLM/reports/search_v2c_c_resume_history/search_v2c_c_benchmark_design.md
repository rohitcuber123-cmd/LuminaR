# V2C-C benchmark protocol, fixed before evaluation

The independently authored cases use normative language/scope labels, not parser outputs. Every field has an explicit default. The main implementation agent must not inspect held-out labels or output until parser freeze. Family membership is exclusive to development, calibration or held-out. Seeded derivatives retain their parent family/split; no random row split. Original query IDs, parent IDs, transformations and seed are retained.

Development and calibration permit bounded deterministic structural improvements. Before final held-out evaluation, source hashes are frozen. Held-out is opened once. A failing held-out safety gate is reported, never silently relabelled or tuned against. Parent-authored generic transformations do not read parser outputs. Held-out transformations execute in the generator without printing held-out texts/labels.

Raw case-weighted metrics, category/scope/family breakdowns and family macro averages prevent thousands of seeded variants from masquerading as independent evidence. Authored and seeded results are separated. Relevance/ranking accuracy is outside this benchmark.

Exact plan match compares all labelled slots plus typed decision and execution eligibility, with Unicode/case/whitespace normalization only for strings, order-insensitive sets, and numeric equivalence. Punctuation in technical/literal entities remains meaningful. Decision accuracy is strict typed-decision equality. Hard constraint precision/recall compare enforced atom sets including comparator exclusivity; non-executable plans enforce no filters. Retained unsupported candidates are still included in exact slot mismatch analysis. False-hard-filter rate counts cases with an unjustified enforced atom divided by all evaluated cases. Unsafe auto-parse rate is executable cases among labelled non-executable cases, with numerator/denominator; total-case incidence is also reported. Comparator accuracy uses supported, executable rating cases; contradiction guards have their own strict recall. Negative and semantic metrics include true empty slots and also report nonempty subsets. Semantic token F1 is the mean case token F1, reported as sum/count and percent, not a classification percentage. Protected preservation requires every authored protected span in a case to survive in literal/entity/semantic fields; span count is retained. Cross-scope canonical leakage here is a plan-vocabulary metric; real authorization/content leakage is separately measured by actual API security requests. Session corruption is measured using full Mongo before/after snapshots in lifecycle sequences, not inferred from parsing alone.

Engineering thresholds: supported contradiction recall100%; observed scope leakage0; observed state corruption0; false hard-filter cases<=1% with all cases reviewed; unsafe auto-parse<3% and0 in supported contradiction/security families; protected entities>=99%; supported rating comparators>=99%. These are bounded benchmark thresholds, not universal language understanding claims.

Calibration uses categorical heuristic evidence, never fabricated probabilities: source-backed, repaired, literal/semantic, unresolved, absent. Typed decisions override every bucket. Bucket tables measure exactness, unsafe execution and clarification counts on the calibration split; held-out is not used to estimate bucket policy. Raw score/probability values are not sent to users. Ordinary Search remains deterministic and model-free.

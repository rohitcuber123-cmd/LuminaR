# Research contribution and novelty assessment

Implementation evidence establishes mechanisms, not comparative superiority. No component currently merits **Strong research contribution** without independent evaluation. This does not diminish the project's engineering breadth; it determines defensible paper language.

## What LuminaR can realistically claim

An implemented systems integration connecting natural-language discovery, context-specific QA, private document processing, contextual assistant tools and circulation entitlements; a reproducible empirical study of those design choices if the planned evaluation is completed; an extensibility proposal for private libraries clearly distinguished from deployed behavior.

The strongest candidate advance is not the stack. It is a measured **retrieval–grounding–abstention tradeoff** for library resource questions, supplemented by maintainable catalogue indexing. Evaluate whether evidence heuristics improve supported-answer completeness without increasing unsupported claims or false refusals, and whether token-aware source coverage improves candidate recall. A negative result is publishable system evidence if methodology and limitations are clear.

## What would strengthen novelty

Create an independently judged library query/QA benchmark with resource spans, publish reproducible scripts and source rights, compare transparent baselines, and report long-tail/unsupported cases. A later multi-library study can show when scoped exact/ANN partitions beat post-filtered global ANN under selective, overlapping catalogues and update failures. Tenant IDs themselves are necessary engineering, not the contribution.

## Unsafe claims

“First intelligent library”, “state of the art”, “eliminates hallucination”, “guarantees semantic understanding”, “millions of concurrent users”, “OCR”, “all books support QA”, “financial payments”, “multi-library isolation implemented”, “new HNSW algorithm”, and “independent human ground truth” for teacher-percentile labels are unsupported.
